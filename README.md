# A-Simple-To-Do
Sentinel

Sentinel is a simple deadline-focused to-do list I made after missing
deadline after deadline

At some point I thought, "Maybe I should stop trusting myself to
remember everything" 😅

So... Sentinel was born;)

The idea is simple: add a task, set a deadline, and let the countdown
remind you how much time you have left before things get serious. :)

AI Usage

I used AI as part of building this project

Project name: I got the name ideas with the help of ChatGPT.

Hero video: The background hero video was generated using
Gemini

JSON: I'm still new to JSON, so I used AI to help me understand
and create the JSON-related parts of the project

I still put the project together and tested the features myself.

How to Use

Open https://a-simple-to-do.vercel.app/

Click Check Sentinel

Add a task

Pick a date and time

Click Add Task

Watch the countdown ⏱️

Finish the task and tick it off

Use the JSON page if you want to import or export your tasks

That's basically it

Because I missed deadline after deadline. 💀
